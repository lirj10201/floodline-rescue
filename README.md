# Floodline Rescue（洪峰倒计时）

面向中学课堂的桥梁工程网页游戏。玩家是暴雨后的救援工程师，要在材料、行动回合和洪峰之间做取舍，把药品、补给和居民送过断桥。

界面语言是英文，方便作为英文课程作业提交。游戏使用简化教学模型：荷载和承载能力都用 **load units** 表示，利用率是需求除以承载能力。需求大于承载能力时测试失败；两者相等时视为刚好达到承载能力，测试通过。画面、判定和文字反馈使用同一套计算结果。

STEM 主题是桥梁工程设计（Engineering），核心概念是荷载、支撑、局部失效，以及材料和时间限制下的工程取舍。

## 本地运行

项目是纯静态网页，不需要构建。在本目录启动任意静态服务器：

```bash
python3 -m http.server 8765
```

浏览器打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。

从上级目录启动也可以，用来确认仓库子路径下资源仍能加载：

```bash
cd ..
python3 -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/Pro/`（文件夹名按实际仓库目录为准）。页面、样式和脚本都使用相对路径。

模型测试不依赖浏览器。需要 Node.js 18 或更新版本：

```bash
node tests/model.test.js
```

已完成的任务关卡保存在本机 `localStorage`（键名 `floodline-rescue-v1`）。首页和 Facilitator Guide 都有 **Clear saved progress**。正在进行的一局刷新后会重开，已通关记录会保留。

## 怎么玩

首页可以 **Start Mission**（按 1 → 2 → 3 解锁），也可以用 **Practice Levels** 直接进入任意一关。练习不会改写任务解锁。

每一关都是：阅读无线电简报和公开规则 → 选择桥型或安装支撑 → 第一关还要先标出预测薄弱点 → 测试 → 看需求、承载能力和利用率 → 修改后再测 → 放行车辆。按钮上会提前写明本次操作消耗的材料和回合，以及操作结束后的预计状态。

音效只在按下按钮后播放，旁边始终有文字说明。图上能点的支撑，右侧都有同名的按钮。动画会遵守系统的“减少动态效果”设置。

1. 把本目录作为仓库根目录推送到 GitHub。
2. 在仓库 Settings → Pages 中，Source 选择发布分支（例如 `main`），文件夹选择 `/ (root)`。
3. 若站点地址是 `https://<用户名>.github.io/<仓库名>/`，不要改资源路径。本项目使用相对路径和哈希路由（`#/play/1/mission`），可以在仓库子路径下运行。

## 三关验收路线

下列路线已由 `tests/model.test.js` 按同一套规则跑通。括号里是教学设定的数值。

### Level 1 · Medicine Run

药车需求固定为西 5、中 7、东 8。

- **会失败的初始方案：** 选择 Timber trestle。东侧承载能力 6，需求 8，测试失败。Center clamp 只给中跨加承载能力，再测仍然是东侧 8/6。反馈会写明加固中跨没有提高东侧承载能力。
- **可以过关的加固：** 拆除 center clamp（归还 1 个 kit），安装 east shoe。东侧承载能力变为 10。答对与本局数据一致的解释后，放行药车。
- **另一条过关路线：** 选择 Steel girder。同一辆药车下，东侧 8/10，全桥通过，不必消耗 kit。
- 第一次测试前必须标出预测薄弱点。预测错误仍可继续。更换桥型或支撑后，旧测试不能放行。复测不消耗回合。

### Level 2 · Supply Split

初始中跨承载能力 8。整车中跨需求 14。拆成两车后，每车中跨需求 8。

- **错误加固：** West knee brace 只加强西岸。测试仍显示中跨 14/8。
- **路线 A：** 拆除错误支撑（kit 全额退回，并消耗 1 回合），安装 center post。中跨承载能力变为 16，测试通过后一次送出整车。公开成本是 2 个 kit、4 个行动回合。
- **路线 B：** Split into two trucks。每车中跨 8/8，刚好达到承载能力，测试通过。两车都要单独测试、单独放行。公开成本是 0 个 kit、7 个行动回合。
- 行动报告会对照本局实际消耗和另一条路线，并说明两条路线为什么都能通过。

### Level 3 · Rising Water

回合从 1 开始。洪峰在 **第 5 回合开始时** 生效，临时中墩和临时斜撑不再提供承载能力。撤离在 **第 16 回合开始时** 截止。放行占 2 个回合，不能跨越第 5 回合。永久中塔占 2 个回合、2 个 kit，洪峰后仍然有效。东侧钢板占 1 个回合、1 个 kit。

三车需求：医护吉普 4/5/3，补给车 5/7/4，撤离巴士 6/10/8。

- **成功路线：** 第 1–2 回合建永久中塔，第 3 回合装东侧钢板，第 4 回合等待。洪峰在第 5 回合到来后，按当前支撑重新测试并依次放行三辆车。
- **另一条成功路线：** 洪峰前测试并送出医护吉普，第 4 回合装上东侧钢板，洪峰后再建中塔，然后测试并送出另外两辆车。
- **会在首轮测试通过、随后失败的路线：** 先装临时斜撑和东侧钢板，巴士测试可以通过（中跨 10/12，东侧 8/12）。此时若放行，行动会占用第 4–5 回合，游戏会阻止放行，并且不扣回合。若等到第 5 回合，临时斜撑被冲走且不退 kit，再测则中跨承载能力为 0，测试失败。继续等待会在第 16 回合因撤离截止失败，并可重试本关。
- 洪峰改变支撑后，洪峰前的通过记录不能再用来放行。
