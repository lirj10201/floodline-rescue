# Floodline Rescue

A structural engineering game. A storm has taken out the bridge to a village. You build the crossing and send the vehicles across.

A part holds only when the load on it is within its capacity. The four crossings are a beam, an arch, a bridge that loses its wood supports in a flood, and a truss.

Open `index.html` in a browser, or start a static server in this folder:

```bash
python3 -m http.server 8765
```

Then open [http://127.0.0.1:8765/](http://127.0.0.1:8765/).
